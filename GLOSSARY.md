# Personal learning

A private learning workspace that turns English educational sources into understandable guided learning.

## Language

**Source**: A text-based PDF or pasted educational text used as learning material.
_Avoid_: Upload (an action, not the material).

**Learning session**: A continuing conversation about a source, with its questions, explanations, and learning progress.
_Avoid_: Account, course (not equivalent).

**Lesson**: A focused explanation of a concept, including examples and opportunities to check understanding.

**Source reference**: A link from an explanation to the relevant source location, including a PDF page where available.
_Avoid_: Proof (a reference does not guarantee correctness).

**Provider**: An external model endpoint used to generate educational responses.
_Avoid_: Tutor (the learning behavior should not be tied to the endpoint).

**Access code**: The private six-digit value used to enter the workspace; not a time-based or one-time code.
_Avoid_: OTP.
